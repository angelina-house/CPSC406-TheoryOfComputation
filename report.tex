  # dfa.py
  class DFA:
      def __init__(self, Q, Sigma, delta, q0, F):
          self.Q = Q  # Set of states
          self.Sigma = Sigma  # Alphabet
          self.delta = delta  # Transition function
          self.q0 = q0  # Initial state
          self.F = F  # Accepting states
  
      def __repr__(self):
          return f"DFA({self.Q},\n\t{self.Sigma},\n\t{self.delta},\n\t{self.q0},\n\t{self.F})"
  
      def run(self, w):
          current_state = self.q0
          for symbol in w:
              if symbol not in self.Sigma:
                  return False
              current_state = self.delta.get((current_state, symbol))
              if current_state is None:
                  return False
          return current_state in self.F  # Accept if in accepting state
  
      def refuse(self):
          # new dfa that refuses input
          return DFA(self.Q, self.Sigma, self.delta, self.q0, set())  
  
  # Example DFA

      dfa = DFA(Q, Sigma, delta, q0, F)

\subsubsection*{Reading Summary and Questions}

Section 2.2 focuses on Deterministic Finite Automata (DFA), which are computational models used to process input strings and determine whether they belong to a specific language. 
A DFA consists of a finite set of states $Q$, a defined input alphabet $\Sigma$, transition rules $\delta$ that 
dictate how the automaton moves between states, a starting state $q_0$, and one or more accepting states $F$ that signify valid inputs.
The operation of a DFA is systematic: it begins in the initial state and processes an input string one symbol at a time, following a unique transition for each symbol. 
Once the entire input has been read, the DFA determines acceptance based on its final state. If it ends in an accepting state, the input is considered valid; otherwise, it is rejected.
Formally, a DFA is defined as a five-tuple $(Q, \Sigma, \delta, q_0, F)$, where $Q$ is the set of states, $\Sigma$ is the input alphabet, $\delta$ is the transition function that maps 
states and inputs to new states, $q_0$ is the initial state, and $F$ is the set of accepting states. 
DFAs are widely used in applications such as text searching, lexical analysis in programming, and pattern recognition. Their deterministic nature makes sure that for any given input, 
the transition path is unique making them both predictable and efficient for structured data processing.
